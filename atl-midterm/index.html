Automata and Language Theory

Lesson 1: Theory of Automata & Finite State Machines

01
Foundations

Theory of Automata, Automaton & Finite State System

1
Theory of Automata
The study of abstract computing devices, or “machines”, dealing with different properties of mathematical models.
An excellent starting point for the theory of computation (computability and complexity require a precise definition of a computer) and introduces formal concepts used across applied Computer Science.
2
Automaton
An abstract model computing machine that processes input sequences according to defined state rules.
3
Finite State System
A mathematical model of a system with discrete inputs and outputs that can be in any one of a finite number of states.
The states of the system summarize the information concerning past inputs needed to determine the behavior of the system on subsequent inputs.
02
Formal Language Building Blocks

Symbols, Strings, Languages, Powers of Σ & Cardinality

1
Symbol
The fundamental building blocks of an alphabet (such as characters 0, 1, a, or b).
2
String
A finite sequence of symbols chosen from an alphabet (for example, 0101).
3
Language
A set of strings formed from an alphabet Σ.
4
Length of String ( |S| )
The total number of symbols present in a string S.
|0110| = 4
5
Empty String ( ε )
A string with zero symbols where |S| = 0, denoted by ε (epsilon).
|ε| = 0
6
Powers of Σ ( Σn )
The set of all strings of a certain length n over the alphabet Σ.
Σ = {0, 1} → Σ2 = {00, 01, 10, 11}
7
Cardinality ( |Σn| )
The number of elements in a set. Given binary alphabet Σ = {0, 1}, the total possible strings of length n is |Σn| = 2n.
Given Σ = {0, 1}, |Σn| = 2n
03
Automata Classification

Types of Finite Automata: DFA vs. NFA Overview

1
Deterministic Finite Automata (DFA)
The simplest model of computation with a fixed number of states where the machine can only be in one state at a time.
After reading any sequence of inputs, it is in a single state; on each input symbol, there is one and only one state to which it can transition, and it has very limited memory.
2
Non-Deterministic Finite Automata (NFA)
A finite automaton with a fixed number of states where the machine can be in multiple states at one time.
04
Formal Definition & Diagram

DFA 5-Tuple & Graphical Representation

DFA 5-Tuple Components: M = (Q, Σ, δ, s, F)
Q
Q — State Alphabet
An alphabet (finite set) of state symbols.
Σ
Σ — Input Alphabet
An alphabet of input symbols read by the machine.
δ
δ — DFA Transition Function
The transition function mapping a state and input symbol to a single next state.
δ : Q × Σ → Q
s
s — Start State
The start (initial) state in Q (s ∈ Q).
F
F — Final State(s)
A set of final (accepting) state or states where F ⊆ Q.
Graphical Representation of a Finite Automaton
1
Vertices (Nodes)
Circles that represent the states of the system.
2
Arcs (Edges)
Directed arrows labeled with an input alphabet symbol, showing state transitions.
3
Initial State
Denoted by an incoming arrow pointing to the state from nowhere.
4
Final State(s)
Indicated by double concentric circles.

Lesson 2: Non-Deterministic Finite Automata (NFA)

01
NFA Properties

Characteristics of Non-Deterministic Finite Automata (NFA)

1
Multiple Next States
Given the current state, there could be multiple next states for a single input symbol.
Can have multiple transitions for the same symbol from the same state.
2
Random or Parallel State Selection
The next state may be chosen at random, or all next states may be chosen in parallel.
3
Zero, One, Two, or More Transitions
For each state, there can be zero, one, two, or more transitions corresponding to a particular symbol.
4
Fewer Restrictions & Simpler Diagrams
NFAs have fewer restrictions than DFAs and therefore make complicated automata easier to understand and depict in a diagram.
5
Empty String Transitions Permitted
Permits empty string (ε) transitions without consuming an input symbol.
6
Backtracking & Space Usage
Backtracking is not always possible, and an NFA requires less space (fewer states) than an equivalent DFA.
7
String Acceptance Condition in NFA
A string is accepted if at least one of all possible transition paths ends in a final state.
02
Formal Definition

NFA 5-Tuple: M = (Q, Σ, δ, s, F)

Q
Q — State Alphabet
An alphabet of state symbols.
Σ
Σ — Input Alphabet
An alphabet of input symbols.
δ
δ — NFA Transition Function (Maps to 2Q)
The transition function mapping a state and input symbol to a subset of states in the power set 2Q.
δ : Q × Σ → 2Q
s
s — Start State
The start state in Q (s ∈ Q).
F
F — Final State(s)
A set of final state or states where F ⊆ Q.
03
Comparison & Conversion

DFA vs. NFA Comparison & Conversion Rules

DFA Properties

1
Single Next State
Transition from a state is to a single particular next state for each input symbol (δ : Q × Σ → Q).
2
No Empty String Transitions
Empty string (ε) transitions are not seen in a DFA.
3
Backtracking & Space
Backtracking is allowed, and a DFA requires more space.
4
String Acceptance
A string is accepted if its single path transits to a final state.
VS

NFA to DFA Conversion Rules

1
Every DFA is an NFA
Every DFA is an NFA, but not vice versa.
A DFA is simply a special case of an NFA where every transition set has size 1.
2
Equivalent DFA Exists for Every NFA
There is an equivalent DFA for every NFA that recognizes the exact same language.
Any NFA with |Q| states can be converted into a DFA with up to 2|Q| states.

Lesson 3: Finite Automata with Epsilon (ε) Moves

01
Epsilon Transitions

Epsilon (ε), Union of Epsilon & ε-Closure

1
Epsilon ( ε )
Means the empty string (a transition taken without reading or consuming any input symbol).
2
Union of Epsilon
Any state on getting a particular input could go to any of the 2Q states, or to no states.
Means that a state on seeing nothing (an empty symbol ε) can also transition spontaneously to one or more states.
3
Reflexive Property: Every State on ε Goes to Itself
Every state on epsilon always goes to itself.
Even if a state diagram does not explicitly draw an ε self-loop on state q, we always include q itself inside ε-closure(q).
4
ε-Closure (Epsilon Closure)
All the states that can be reached from a particular state only by seeing the epsilon (ε) symbol.
Includes the starting state itself plus all states reachable by following one or more consecutive ε arrows.
02
Conversion Algorithm

Procedure for Converting ε-NFA to NFA

1
Step 1 — Find Initial ε-Closure
Determine the ε-closure of the current state q.
S1 = ε-closure(q) = δ(q, ε)
2
Step 2 — Follow Input Symbol Transitions
For each input symbol a, evaluate the set of states reached from the result of Step 1.
S2 = δ(S1, a) = δ(δ(q, ε), a)
3
Step 3 — Take Final ε-Closure
Take the ε-closure of all states obtained in Step 2 to produce the final transition set.
S3 = ε-closure(S2)
4
Step 4 — Complete ε-NFA to NFA Transition Formula
Combines Steps 1–3 into a single formal transition equation for state q and input symbol a.
δ(q, a) = ε-closure( δ( δ(q, ε), a ) )

Lesson 4: Regular Expressions & Simplification Identities

01
Definitions & Closures

Regular Expressions, Regular Languages, x* & x+

1
Regular Expressions
Simple expressions that easily describe the languages accepted by finite automata.
Can also be described as a sequence of pattern that defines a string.
2
Regular Languages
The languages accepted by some regular expression (and recognized by a DFA or NFA).
3
x* (Kleene Star)
In a regular expression, means zero or more occurrences of x.
x* = { ε, x, xx, xxx, ... }
4
x+ (Positive Closure)
In a regular expression, means one or more occurrences of x (excludes ε unless ε ∈ x).
x+ = xx* = { x, xx, xxx, ... }
02
Regular Expression Operators

Operators Used in Regular Expressions & Regular Languages

1
Union ( ∪, |, or + )
If R1 and R2 are regular expressions, then R1 | R2 (also written as R1 ∪ R2 or R1 + R2) is also a regular expression.
Matches any string that belongs to L(R1) or L(R2).
L(R1 | R2) = L(R1) ∪ L(R2) = R1 ∪ R2
2
Concatenation ( R1R2 or R1.R2 )
If R1 and R2 are regular expressions, then R1R2 (also written as R1.R2) is also a regular expression.
Joins a string from R1 followed immediately by a string from R2.
L(R1R2) = L(R1) concatenated with L(R2) = { xy : x ∈ R1 and y ∈ R2 }
3
Kleene Closure ( R1* )
If R1 is a regular expression, then R1* (the Kleene closure of R1) is also a regular expression.
Concatenates zero or more strings chosen from R1.
L(R1*) = ε ∪ L(R1) ∪ L(R1R1) ∪ L(R1R1R1) ∪ ... = { x1x2x3...xk : k ≥ 0 and each xi ∈ R1 }
03
Simplification Laws

Identities of Regular Expressions (Simplification)

1
Union with Empty Set ( Φ )
Adding the empty language Φ via union leaves R unchanged.
Φ + R = R
2
Concatenation with Empty Set ( Φ )
Concatenating any regular expression R with the empty set Φ always yields the empty set Φ.
ΦR = RΦ = Φ
3
Concatenation with Empty String ( ε )
Concatenating R with the empty string ε leaves R unchanged.
εR = Rε = R
4
Kleene Closure of ε and Φ
The Kleene star of both the empty string and the empty set equals the empty string ε.
ε* = ε and Φ* = ε
5
Union of Empty Set and Empty String
The union of Φ and ε simplifies to ε.
Φ + ε = ε
6
Idempotent Law of Union
Taking the union of a regular expression R with itself yields R.
R + R = R
7
Product of Identical Kleene Closures
Concatenating R* with R* produces R*.
R*R* = R*
8
Positive Closure Identity ( R+ )
Concatenating R with R* in either order produces one or more occurrences (R+).
RR* = R*R = R+
9
Nested Kleene Closure
Applying Kleene closure twice is redundant and simplifies to R*.
(R*)* = R*
10
Kleene Star Expansion Identity
Zero occurrences (ε) unioned with one or more occurrences (RR* or R*R) equals R*.
ε + RR* = ε + R*R = R*
11
Absorption of Q into P*Q and QP*
Since P* already includes ε, Q is already contained inside P*Q and QP*.
P*Q + Q = P*Q and QP* + Q = QP*
12
Idempotent Union of P*Q
Unioning P*Q with itself simplifies to P*Q.
P*Q + P*Q = P*Q
13
Sliding / Shift Rule for Concatenation
Repeating PQ followed by P is identical to starting with P followed by repeating QP.
(PQ)*P = P(QP)*
14
Closure of Union Equivalences
All three closure expressions generate the exact same set of strings over P and Q.
(P + Q)* = (P*Q*)* = (P* + Q*)*
15
Left and Right Distributive Laws
Concatenation distributes over union from both the right and the left.
(P + Q)R = PR + QR and R(P + Q) = RP + RQ
16
Product of (R + ε) with R*
Multiplying R* by (R + ε) on either side simplifies to R*.
(R + ε)R* = R*(R + ε) = R*
17
Union of (R + ε) with R*
Since both R and ε are already in R*, their union simplifies to R*.
(R + ε) + R* = R*
18
Optional R Followed by Its Closure
(R + ε) concatenated with (R + ε)* simplifies to R*.
(R + ε)(R + ε)* = R*
19
Two-Sided Optional R Closure
Multiplying (R + ε)* by (R + ε) on both sides still simplifies to R*.
(R + ε)(R + ε)*(R + ε) = R*

Lesson 5: Mealy and Moore Machines

01
Transducers

Finite Automata with Output & Sequential Machines

1
Finite Automaton with Output
A finite-state machine that produces an output sequence as it reads an input sequence.
Unlike DFAs and NFAs (which only accept or reject strings), output machines emit symbols from an output alphabet Δ.
2
Sequential Machines
Finite automata that generate output based on input symbols and machine states.
02
6-Tuple Definition

Mealy & Moore Machine 6-Tuple Components

Q
Q — Set of States
A finite set of states.
Σ
Σ — Input Alphabet
The finite set of input symbols.
q0
q0 — Initial State
The initial (start) state where q0 ∈ Q.
δ
δ — Transition Function
The transition function which maps the current state and current input symbol to the next state.
δ : Q × Σ → Q
Δ
Δ — Output Alphabet
The finite set of output symbols emitted by the machine.
λ
λ — Output Function
Defines how output symbols are generated: Q × Σ → Δ in a Mealy Machine, or Q → Δ in a Moore Machine.
Mealy Output Function: λ : Q × Σ → Δ Moore Output Function: λ : Q → Δ
03
Mealy vs. Moore

Comparing Mealy Machine and Moore Machine

Mealy Machine

1
Output Dependency
Output symbol depends upon the present input symbol AND the present state of the machine.
2
Where Output is Placed
Output is associated with the transitions (arcs/edges), written as input / output on each arrow.
3
Mealy Output Function
Maps state and input symbol to an output symbol.
λ : Q × Σ → Δ
VS

Moore Machine

1
Output Dependency
Next state is decided by current state and input symbol, but the output symbol depends ONLY on the present state of the machine.
2
Where Output is Placed
The output is associated in the states themselves (written inside each state node as q / output).
3
Moore Output Function
Maps each state directly to an output symbol.
λ : Q → Δ
